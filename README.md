# HATIM 5G (مبني على Hua4GMon)

نسخة مخصصة للاستخدام الشخصي لراوترات Huawei، مع جعل العربية اللغة الافتراضية وإعادة تسمية التطبيق إلى HATIM 5G. تم الإبقاء على منطق الاتصال وقراءة البيانات الأصلي قدر الإمكان.

## تنبيه
- الترجمة العربية تغطي العبارات الأساسية، وقد تبقى بعض العبارات بالإنجليزية أو الروسية حتى تكتمل ترجمتها.
- لم يتم بناء APK أو اختباره على جهازك ضمن هذه الحزمة. اختبر الاتصال وقراءة الإشارات وقفل النطاقات قبل الاعتماد عليها.
- المشروع الأصلي مرخّص GPL-3.0؛ احتفظ بملف LICENSE وإشعارات الحقوق عند التعديل والتوزيع.

## بناء Android
استخدم GitHub Actions الموجود في `.github/workflows/build-android.yml` بعد رفع محتويات هذا المجلد إلى مستودع جديد.

## التغييرات في هذه النسخة
- الاسم الظاهر: HATIM 5G.
- اللغة الافتراضية: العربية.
- إضافة خيار العربية إلى قائمة اللغات.
- الاحتفاظ بمنطق الاتصال الأصلي في `core/` دون إعادة كتابته.
